# Описание проекта
Цель: Выявить характеристики, которые помогают не просто привлекать новых пользователей, а удерживать их и превращать в постоянных. Для этого нужно повысить долю клиентов, которые после одной покупки приходят снова и совершают новые.
Требуется помочь команде маркетинга лучше понять поведение пользователей. Для этого нужно провести исследовательский анализ данных, чтобы выяснить, какие пользователи с большей вероятностью возвращаются на платформу и делают заказы повторно. Это позволит решить несколько задач:
* Быстро выявлять перспективных клиентов и предлагать им персонализированные условия;
* Точно настраивать рекламу на аудитории с высокой вероятностью возврата;
* Оптимизировать маркетинговые бюджеты;
* Повысить общий уровень удержания клиентов.

# Инструкции по запуску проекта:

* Запустить файл main.py командой: python main.py

# Итоги анализа
В ходе исследования данные подверглись обработке.
* Были удалены данные, для которых количество билетов превышало 99-ый перцентиль.
* Были удалены заказы с отрицательной ценой.
* Были отфильтрованы заказы, для которых цена превышала 99-ый перцентиль.
* Цена заказа была приведена к рублям.
* Для лучшей аналитики данные были сгруппированы для выделения характеристик пользователей.

Всего в выборке присутствует информация о 21050 пользователях, наибольшая часть из которых сделала меньше 5 заказов. Большое внимание уделено цене заказа и среднему времени между заказами. На основании полученной информации, они больше всего влияют на возвращение клиента, однако среднее время между заказами влияет именно на вернувшихся клиентов для оценки будущих возвращений. Также, для мониторинга возвращения клиента после повторного заказа следует обратить внимание на средний интервал между заказами, так как можно оценить, когда клиент вернётся снова.

Больше всего пользователей возвращается в данных сегментах:
* Сделавшие первый заказ с компьютера
* Чей первый заказ был на выставку или театр
* Сделавшие первый заказ в Шанырском регионе и Светополянском округе
